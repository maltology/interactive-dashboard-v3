# Interactive Dashboard V3 — Perpustakaan

Papan pemuka interaktif untuk merekod dan menganalisis operasi perpustakaan.

## Modul
- Statistik Pinjaman Buku: nama peminjam, No IC, buku, kod, tarikh pinjam/pulang, status dan carian.
- Statistik Kehadiran Pengunjung: rekod pengunjung dan trend 7 hari.
- Statistik Penggunaan ICT/PC: PC, masa mula/tamat, pengiraan jam dan trend 7 hari.
- Dashboard utama dengan KPI operasi.
- Light/Dark mode.
- Data persistent menggunakan localStorage.

## Jalankan
`npm install`

`npm run dev`

## Build
`npm run build`
